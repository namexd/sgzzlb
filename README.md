# 三国志战略版配将分析小程序

面向活跃中高战玩家的微信小程序。V1 重点是“可解释阵容评分”：不只给分数，还给维度拆解、短板、对位风险和替代战法。

## 当前实现

- 原生微信小程序工程，可用微信开发者工具打开本目录。
- 零依赖 Node.js 后端原型，默认端口 `8787`。
- 静态管理后台，启动后访问 `http://127.0.0.1:8787/admin/`。
- 官方公开资料库快照：武将 112、战法 174、装备 57、兵种 12。
- 首页阵容评分工作台：赛季/场景、兵种、三武将、六战法、红度、评分报告。
- 资料库：四类资料检索，不加载官网图片。
- 对位预览：本方阵容与环境模板做规则化对比。
- 我的：内测订阅开关、保存阵容、本地/远程 API 切换、V1.5 共存入口。
- 后台：运营概览、资料快照、评分规则、原创卡牌审核、战报导入队列、订阅权益、审计日志。
- 管理后台 store 本地持久化到 `.runtime/admin-store.json`，包含规则草案、资产审核、阵容样本和审计日志，支持导出和重置。
- 设计记录：见 `DESIGN.md` 和 `docs/design/index.md`。

## 命令

```bash
npm run fetch:data
npm run dev:server
npm test
```

启动服务后：

- 小程序本地快照仍可离线运行。
- `我的 -> 服务端连接` 可切换远程 API，并检测 `http://127.0.0.1:8787`。
- 管理后台地址：`http://127.0.0.1:8787/admin/`。
- 管理接口默认 token：`dev-admin-token`，本地开发用，不能用于生产。

## 数据说明

`scripts/fetch-official-catalog.mjs` 会抓取官方公开资料库接口并生成 `data/catalog.json` 和小程序运行时使用的 `data/catalog.js`。脚本会剔除官方图片 URL，只保留文字字段和原创资产生成状态。

商业化上线前需要确认官方资料字段、长篇文案和素材展示边界。

## 后端和后台说明

当前后端用 Node.js 内置 `http` 模块实现，零依赖，代码在 `server/`。它提供 V1 API、阵容保存 API、管理后台 API 和静态后台托管。管理后台数据默认写入 `.runtime/admin-store.json`，适合原型验证；生产化时需要替换为数据库、登录鉴权、用户归属、支付权益和持久审计。
