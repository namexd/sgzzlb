# 原创资产策略

## 原则

前台和后台不得引用官网图片、游戏立绘、竞品截图或官方卡牌边框。当前数据快照已剔除官方图片 URL，只保留文字字段和原创资产状态。

当前页面可以展示两类合规资产：

- 原创 CSS 卡面：无图片时使用阵营色、姓名首字和兵种适性兜底。
- 已审核原创图片：通过 OSS 或本地静态目录引用，必须保留生成、审核和风险记录。

## 生成要求

- 输入只能是文字 prompt，描述历史人物、阵营气质、原创卡牌系统和原创边框。
- 不允许把官网图、游戏立绘、竞品截图作为参考图。
- 不允许生成可与官方卡牌混淆的姿势、服饰细节、背景和边框。
- 每张图必须记录模型、prompt、批次、审核状态和相似度风险。
- 上传到 OSS 前必须确认图片不含官方 UI 元素、官方图标、官方卡框或游戏立绘特征。

## 当前产物边界

- `data/catalog.json`、`data/catalog.js`：资料快照，不能恢复官方图片 URL。
- `images/icons/`、`src/static/icons/`：应用图标和 tab 图标，必须保持原创。
- `server/oss.js`：只负责上传和生成 URL，不负责审核；审核结论必须在调用上传前完成。
- `admin` 侧资产审核记录只代表内部流程记录，不代表法律合规最终结论。

## 上线检查

- 检查产物目录中不存在 `image.aligames.com`、`cloud.lingxigames.com`、`cdn-cn.lingxigames.com` 等官方素材 URL。
- 对每张生成卡做人审，风险图不进入线上包。
- 商业化上线前确认资料字段、长文案和视觉资产的法律边界。
- 部署前用全文搜索复核官方素材域名和明显外部图链。
